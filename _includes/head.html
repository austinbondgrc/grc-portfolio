{%- comment -%} One title, one description, decided once. The home page's title is the site title alone; every other page is "Page | Site", because a browser tab and a search result both lead with the specific thing rather than the generic one. A page that defines `description:` gets its own summary; the rest fall back to site.description, which is written as a whole-site summary rather than as a subtitle, so the fallback still reads as a description. Both are computed before use because og:title has to repeat : it used to read page.title directly, and the home page defines no title, so its card arrived with an empty headline. {%- endcomment -%} {%- if page.url == "/" -%} {%- assign seo_title = site.title -%} {%- else -%} {%- assign seo_title = page.title | append: " | " | append: site.title -%} {%- endif -%} {%- assign seo_desc = page.description | default: site.description -%} {%- assign og_alt = "Austin Bond — GRC Portfolio: an ISO 27001:2022 ISMS build for a fictional German company" -%} <title>{{ seo_title | escape }}
